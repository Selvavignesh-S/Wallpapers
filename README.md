# Wallpapers

A personal, hand-picked collection of about 1,290 wallpapers (~2.4 GB), curated to my own taste. Dark, minimal, nord/gruvbox/catppuccin-style themes, pixel art, space, landscapes, cityscapes, lofi, and a few classic paintings.

Browse the folder, pick the ones you like, and use them.

> **I did not create most of these images.** This is a curated collection gathered from the sources listed under [Credits](#credits). All rights belong to the original artists and photographers.

## Usage

**Download one image:** open it in the repo and click the download button, or use the raw link.

**Clone everything** (about 2.4 GB):

```bash
git clone https://github.com/Selvavignesh-S/Wallpapers.git
```

**Faster, without the full history:**

```bash
git clone --depth 1 https://github.com/Selvavignesh-S/Wallpapers.git
```

**Pull a single file:**

```bash
curl -LO "https://raw.githubusercontent.com/Selvavignesh-S/Wallpapers/main/FILE_NAME"
```
